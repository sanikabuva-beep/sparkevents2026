## Deploy to GitHub + Vercel

1. Create a new GitHub repository.
2. Upload / push the contents of this folder to the repo root (so `index.html` is at the root).
3. Go to [vercel.com](https://vercel.com) → Add New Project → Import the repo.
4. Framework Preset: **Other** (static). No build command needed.
5. Deploy.

Your site will be live at `https://your-project.vercel.app`.

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```
